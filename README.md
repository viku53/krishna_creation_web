# Krishna Creation Photography 📸

Welcome to the official source code repository for the **Krishna Creation** portfolio website! 
This is a modern, fast, and fully responsive photography portfolio built to showcase breathtaking photography, cinematic videos, short reels, and instant printing services.

## 🌐 Live Website
**[https://krishnacreationphotography.com](https://krishnacreationphotography.com)**

## ✨ Features
* **Photography Gallery**: High-performance, categorized photo galleries with lazy-loading and infinite scroll.
* **Cinematic Videos**: Dedicated video portfolio with modal playback.
* **Reels Interface**: A mobile-first, TikTok/Instagram style vertical swipe interface for short video highlights.
* **Services**: Detailed breakdown of offerings, including Photography, Videography, and Instant Event Printing.
* **Contact Integration**: Integrated contact form and direct WhatsApp/Phone call links.
* **Dark Mode Aesthetics**: Sleek, modern, premium UI/UX design.

## 🛠 Tech Stack
* **Framework**: React 19 + Vite
* **Routing**: React Router DOM v7
* **Styling**: Modern CSS (with animations & transitions)
* **Icons**: Lucide React & React Icons
* **Forms**: EmailJS for direct contact inquiries
* **SEO**: React Helmet Async

## 🚀 Local Development

1. **Clone the repository**
   ```bash
   git clone <your-repository-url>
   cd Trial
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Environment Variables**
   Create a `.env` file in the root directory based on `.env.example` and add your keys (e.g., EmailJS keys, contact numbers).

4. **Start Development Server**
   ```bash
   npm run dev
   ```
   The app will typically run on `http://localhost:5173`.

## 📦 Deployment (GitHub Pages)
This project is configured to be hosted easily on platforms like GitHub Pages, Vercel, or Netlify. A `CNAME` file is included in the `public` folder to automatically link the custom domain on build.

To build the project for production:
```bash
npm run build
```
This generates the optimized production files inside the `dist/` directory.
