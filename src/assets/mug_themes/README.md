# Mug Themes Folder

Drop your theme images here. Supported formats: `.webp`, `.png`, `.jpg`, `.jpeg`

## Naming Convention
Use descriptive names — they become the theme label shown to users.

Examples:
- `birthday.webp` → "Birthday"
- `anniversary.webp` → "Anniversary"
- `love.webp` → "Love"
- `floral_pattern.webp` → "Floral Pattern"

The theme image should have a clearly visible **empty/blank area on the LEFT side** where the user's uploaded photo will be placed.

## How it Works
1. User picks a theme → it wraps around the 3D mug preview
2. The left portion (~1/3) shows the user's uploaded photo overlaid
3. Right 2/3 shows your theme design

Recommended image dimensions: **200×90mm print area** (2362×1063 px at 300 DPI)
